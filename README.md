# 🚀 SynerRH

O **SynerRH** é uma aplicação Full Stack de **Gestão de Pessoas e Desempenho**, desenvolvida para centralizar informações sobre colaboradores, avaliações de desempenho, Planos de Desenvolvimento Individual (PDI), feedbacks, ciclos de avaliação e indicadores estratégicos de RH.

O projeto une minha experiência profissional na área administrativa aos conhecimentos adquiridos em **Análise e Desenvolvimento de Sistemas**, aplicando tecnologia a um contexto real de negócio.

## 💡 Como surgiu o projeto

O SynerRH não nasceu como um sistema completo de gestão de pessoas.

Sua primeira versão chamava-se **People Performance**, inicialmente focada no acompanhamento de desempenho dos colaboradores.

A ideia surgiu da união de dois pilares importantes da minha trajetória: **mais de 10 anos de experiência na área administrativa**, trabalhando com processos, dados, atendimento e gestão, e minha formação em **Análise e Desenvolvimento de Sistemas**.

Durante minha transição para a tecnologia, percebi que poderia transformar essa experiência corporativa em código, desenvolvendo uma aplicação com contexto real de negócio e, ao mesmo tempo, colocando em prática meus conhecimentos em desenvolvimento de software.

Com a evolução do projeto, o escopo foi muito além da análise de performance. A aplicação passou a incorporar gestão de colaboradores, avaliações de desempenho, PDIs, feedbacks, ciclos, cronograma e indicadores estratégicos.

Nesse momento, **People Performance já não representava tudo o que o projeto havia se tornado**.

Foi então que nasceu o **SynerRH**.

O nome representa a **sinergia entre pessoas, gestão, desenvolvimento e tecnologia**.

Mais do que um projeto de portfólio, o SynerRH representa a conexão entre minha trajetória profissional anterior e a carreira que estou construindo em tecnologia: de um lado, minha experiência com **processos, organização, dados e visão de negócio**; do outro, o desenvolvimento de uma aplicação Full Stack, do frontend ao banco de dados.

---

## 🎯 Objetivo

O objetivo do SynerRH é simular uma aplicação corporativa capaz de centralizar informações importantes para a gestão e o desenvolvimento de colaboradores.

Durante sua construção, o projeto permitiu aplicar na prática conceitos como:

- Desenvolvimento Frontend e Backend
- Componentização e responsividade
- Criação e consumo de API REST
- Regras de negócio
- Modelagem e relacionamentos de banco de dados
- Integração entre frontend, backend e banco
- Versionamento com Git e GitHub
- Configuração de ambientes
- Migração de banco de dados
- Deploy de uma aplicação Full Stack

---

## ✨ Funcionalidades

O sistema conta com:

- 📊 **Dashboard** com indicadores de Gestão de Pessoas
- 👥 **Colaboradores** e perfis individuais
- 🎯 **Avaliações de desempenho** e ciclos de avaliação
- 📈 **PDI** com acompanhamento de progresso e status
- 💬 **Feedbacks** dos colaboradores
- 📅 **Cronograma** de atividades e ciclos
- 🤖 **People Insights** para análise dos dados do sistema
- 🔎 **Pesquisas e filtros**
- 📱 **Interface responsiva** para desktop e dispositivos móveis

## 🏗️ Arquitetura

O **SynerRH** possui frontend e backend separados, conectados por meio de uma **API REST**.

```text
React + TypeScript
        ↓
      API REST
        ↓
Fastify + TypeScript
        ↓
    Prisma ORM
        ↓
    PostgreSQL
```
